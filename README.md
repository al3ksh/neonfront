# NeonFront

Overwatch-style FPS with LAN multiplayer.

## Download

1. Go to [Releases](../../releases/latest) and download **NeonFront-Launcher.exe** (Windows 64-bit).
2. Run it. The launcher installs the game to `%LOCALAPPDATA%\NeonFront`, keeps itself and the game up to date, and starts the game with **PLAY**.

The other release files (`manifest.json`, `NeonFront-<version>-win64.zip`) are used by the launcher; you do not need to download them.
